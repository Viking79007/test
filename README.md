# Telegram Keyword Notifier для macOS

Нативное macOS-приложение на SwiftUI для Apple Silicon (M1/arm64). Оно читает обновления Telegram-бота через Telegram Bot API и показывает системное уведомление macOS, если новое сообщение в выбранном чате содержит одно из заданных ключевых слов.

## Важные ограничения Telegram

Приложение использует официальный Bot API:

- бот должен быть добавлен в нужную группу, канал или чат;
- для групп бот видит все сообщения только если отключить privacy mode у бота через `@BotFather` (`/setprivacy -> Disable`) или если сообщение адресовано боту;
- для каналов бот обычно должен быть администратором канала;
- приложение не читает личный аккаунт Telegram пользователя и не обходит ограничения Telegram.

## Сборка под Mac M1

На Mac с установленным Xcode:

```bash
./scripts/build_app.sh
open dist/TelegramKeywordNotifier.app
```

Скрипт собирает релизный arm64-бинарник, упаковывает его в `dist/TelegramKeywordNotifier.app` и при наличии `codesign` выполняет ad-hoc подпись.

Если нужно изменить bundle identifier:

```bash
BUNDLE_ID=com.yourcompany.TelegramKeywordNotifier ./scripts/build_app.sh
```

## Настройка

1. Создайте бота через `@BotFather` и скопируйте токен.
2. Добавьте бота в нужный Telegram-чат.
3. Запустите приложение.
4. Вставьте токен бота.
5. Укажите ID чата или `@username` группы/канала.
   - Поле можно оставить пустым, тогда приложение будет проверять все обновления, которые получает бот.
   - Для приватных групп удобнее узнать numeric chat id через временный запуск без фильтра или через Telegram Bot API.
6. Введите ключевые слова или фразы: каждое с новой строки, через запятую или через точку с запятой.
7. Нажмите `Разрешить уведомления`, затем `Запустить`.

Приложение сохраняет настройки локально в `UserDefaults`.

## Поведение

- Проверка сообщений выполняется long polling-запросом `getUpdates`.
- Совпадение ключевых слов регистронезависимое.
- Поддерживаются обычные сообщения и подписи к медиа (`text` и `caption`).
- По умолчанию старые сообщения пропускаются при запуске, чтобы не присылать уведомления за историю.
- Кнопка `Сбросить позицию` очищает сохраненный `update_id`.
